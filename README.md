# 离散时间序列与 DTFT 分析器

一个基于 React + Vite 的教学型 Web 应用，用于展示数字信号处理中的典型离散时间序列，并联动显示其数值 DTFT 幅度谱与相位谱。

## 功能

- 典型序列列表：单位冲激、单位阶跃、矩形、实指数、三角、延时冲激。
- 自定义序列：支持对典型序列进行加减乘除、移位和简单组合。
- 范围控制：可调整 `n` 范围、`ω` 范围和频谱采样点数。
- 图形展示：
  - 序列图采用散点/茎叶式表现。
  - 幅度谱与相位谱采用折线图。
- 数据精度：界面显示统一保留到最多两位小数。
- 文件上传接口预留：后续可接入离散信号、音频、视频等输入分析流程。

## 自定义表达式

支持以下内置函数：

- `delta(n)`
- `u(n)`
- `rect(n, N)`
- `tri(n, N)`
- `expseq(a, n)`
- `sinseq(omega, n)`
- `cosseq(omega, n)`
- `abs(x)`
- `pow(a, b)`
- `pi`

示例：

- `delta(n) + 0.5 * rect(n, 6)`
- `u(n) - u(n - 4)`
- `expseq(0.8, n) * rect(n, 8)`
